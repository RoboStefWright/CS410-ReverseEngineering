# CS410-ReverseEngineering

In this class I learned about reverse engineering, assembly language, and security. The first project was to convert binary to assembly language and then to C++. The document shows what the assembly language means, and the C++ file is the conversion of it. The second project was to improve on the first by adding some security. Descriptions of the vulnerabilities that should be addressed are in the document. The C++ file has those vulnerabilities commented on as well as some fixed within the code.
